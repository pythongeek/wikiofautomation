## Turn Any WordPress or WooCommerce Site into a Native AI Agent Node

Modern AI agents (Claude, ChatGPT, Perplexity, Cursor, custom MCP clients) don't just scrape HTML—they consume structured **Model Context Protocol (MCP)** manifests, verify citation metadata, and read `/llms.txt`.

**WebMCP Nexus Pro (v1.1.4)** is a zero-bloat, self-hosted PHP 8.1+ WordPress toolkit that gives your site:
- **~52 Built-In MCP Tools:** Exposes content, search, navigation, ACF fields, and WooCommerce product/cart tools over `/wp-json/wpwebmcp/v1/manifest` + WordPress 6.9+ Abilities API bridge.
- **0–100 AEO Audit & Leaderboard:** Grades every post across 7 weighted signals (JSON-LD coverage, FAQ/HowTo schema, author/date metadata, freshness, exposure tier, excerpt, featured image) using fast local DB queries.
- **Multi-Signal Intent Firewall & Agent Governance:** Classify, allow, throttle (RPM), or block AI bots (`GPTBot`, `ClaudeBot`, `PerplexityBot`) per path with IP/rDNS CIDR verification.
- **Smart SEO Plugin Coexistence:** Defer, Off, or Emit sanitized single-`@graph` JSON-LD alongside Rank Math, Yoast, AIOSEO, and SEOPress without duplicate schema conflicts.
